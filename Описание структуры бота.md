
## Требования

- Python **3.10+**
- Учётная запись и токен бота в мессенджере MAX

## Установка

```bash
pip install -r requirements.txt
```


## Запуск

```bash
python -m bot.main
```

## Архитектура

Код разделён на два слоя:

1. **Каркас** (`bot/*`) — конфигурация, сборка бота и UI-компоненты.
2. **Обработчики** (`bot/handlers/*`) — бизнес-логика, сгруппированная по
   роутерам `maxapi.Router`.

```
bot/
├── __init__.py         # публичный API пакета: create_bot()
├── config.py           # чтение и валидация конфигурации
├── main.py             # точка входа: create_bot() + запуск polling
├── keyboards.py        # фабрики inline-клавиатур
├── payloads.py         # типизированные CallbackPayload (контракт UI ⇄ логики)
└── handlers/
    ├── __init__.py     # экспорт роутеров и setup_error_handlers()
    ├── start.py        # Router "start": bot_started, /start, /help
    ├── callbacks.py    # Router "callbacks": обработка inline-кнопок
    └── errors.py       # глобальный обработчик ошибок
```

Зависимости модулей направлены вниз/в стороны и не образуют циклов:

```
main.py → config.py, handlers/*
keyboards.py → payloads.py
handlers/* → keyboards.py, payloads.py
```


## Обзор файлов

### `bot/config.py`

Читает `.env`, экспортирует `BOT_TOKEN`. Падает с понятной ошибкой, если
токен не задан. Любые новые настройки (логирование, параметры бота) —
сюда.

### `bot/main.py`

Точка входа. Функция `create_bot()` собирает приложение:

- создаёт `Bot` и `Dispatcher`;
- подключает роутеры через `dp.include_routers(start_router, callbacks_router)`;
- регистрирует обработчик ошибок `setup_error_handlers(dp)`.

`main()` запускает polling. Новый роутер подключается добавлением одной
строки в `create_bot()`.

### `bot/payloads.py`

Определения `CallbackPayload` — **контракт между кнопками и обработчиками**.
Каждый класс = одно действие кнопки. `pack()` сериализует данные в
`callback_data` (строка), `PayloadFilter.filter()` распаковывает обратно в
типизированный объект. Значения валидируются pydantic (лимит payload —
1024 байта).

### `bot/keyboards.py`

Фабрика `main_menu_keyboard()` возвращает `Attachment` типа
`inline_keyboard` с кнопками `CallbackButton`. Данные кнопок берутся из
`payloads.py`, поэтому UI и логика всегда согласованы.

### `bot/handlers/start.py`

Роутер `router = Router(router_id="start")`:

- `bot_started` — reply-кнопка «Начать»;
- `start_command` (`CommandStart()`) — команда `/start`;
- `help_command` (`Command("help")`) — команда `/help`.

Описание команды для списка команд берётся из docstring
(`commands_info: ...`), механизм — в `maxapi` автоматически.

### `bot/handlers/callbacks.py`

Роутер `router = Router(router_id="callbacks")`. Каждый обработчик
фильтруется своим payload-классом:

```python
@router.message_callback(HelloPayload.filter())
async def on_hello(event: MessageCallback, payload: HelloPayload):
```

### `bot/handlers/errors.py`

Регистрирует глобальный `@dp.errors()` обработчик. Любая необработанная
ошибка в хендлере логируется с трейсбеком, `dispatcher` продолжает работу.

## Добавление новой команды

1. В `bot/handlers/start.py` (или в новом роутере) добавьте обработчик:

   ```python
   @router.message_created(Command("echo"))
   async def echo_command(event: MessageCreated, args: list[str]):
       """commands_info: Повторить переданный текст."""
       await event.message.answer(text=" ".join(args))
   ```

   `args` автоматически подставляется фильтром `Command` (аргументы после
   имени команды).

2. Если создали новый роутер — подключите его в `create_bot()` в `main.py`.

## Добавление новой inline-кнопки

1. **`bot/payloads.py`** — опишите действие:

   ```python
   class InfoPayload(CallbackPayload):
       pass
   ```

   Или данные кнопки:

   ```python
   class ProductPayload(CallbackPayload):
       product_id: int
   ```

2. **`bot/keyboards.py`** — добавьте кнопку в клавиатуру:

   ```python
   CallbackButton(text="Инфо", payload=InfoPayload().pack())
   ```

3. **`bot/handlers/callbacks.py`** — добавьте обработчик:

   ```python
   @router.message_callback(InfoPayload.filter())
   async def on_info(event: MessageCallback, payload: InfoPayload):
       await event.callback.answer("Инфо")
       await event.send(text="...")
   ```

Новый payload **невозможно** разобрать без обработчика: фильтр `filter()`
вернёт `False`, и событие будет проигнорировано — рассинхронизация
кнопки и логики не «прожёвывается» молча.

## Обработка ошибок

- Ошибки внутри хендлеров логируются `handlers/errors.py`.
- Для точечной логики по исключениям используйте `dp.errors(ExceptionTypeFilter(...))`.
- Для диалогов/состояний используйте FSM:
  `dp.fsm.set_state(chat_id, user_id, state)` и фильтр `StateFilter(state)`
  .
