# База данных: описание таблиц

PostgreSQL. Схема описана ORM-моделями в `db/models/`, миграции — в `alembic/versions/`.
ORМ-модели — единственный источник истины; DDL генерируется из них.

## Обзор

| Таблица | Модель | Описание |
|---|---|---|
| `subject` | `Subject` | Образовательный предмет / субъект РФ |
| `city` | `City` | Город, привязанный к субъекту |
| `EGAS` | `EGAS` | Электронная образовательная система (ЭГАС) |
| `educational_institution` | `EducationalInstitution` | Образовательное учреждение |
| `EI_with_EGAS` | — (таблица связи) | Учреждения ↔ ЭГАС (M:N) |
| `student` | `Student` | Ученик образовательного учреждения |
| `partner` | `Partner` | Партнёр-компания |
| `bonus` | `Bonus` | Бонус от партнёра |
| `student_bonus` | — (таблица связи) | Ученики ↔ бонусы (M:N) |
| `admins` | `Admin` | Администраторы бота |
| `applications` | `Application` | Заявки партнёров |

## Детали таблиц

> Примечание про ID: во всех таблицах `id` — `INTEGER GENERATED BY DEFAULT AS IDENTITY`
> (автоинкремент). Исключений нет.

### subject

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `name` | VARCHAR(255) | NOT NULL | Название |

### city

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `name` | VARCHAR(255) | NOT NULL | Название города |
| `subject_id` | INTEGER | NOT NULL, FK → `subject.id` | Субъект РФ |

### EGAS

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `name` | VARCHAR(255) | NOT NULL | Название системы |
| `API_file` | VARCHAR(255) | NOT NULL | Файл (описание) API |

### educational_institution

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `name` | VARCHAR(255) | NOT NULL | Название учреждения |
| `city_id` | INTEGER | NOT NULL, FK → `city.id` | Город |

### EI_with_EGAS

Связующая таблица (M:N `educational_institution` ↔ `EGAS`).

| Колонка | Тип | Ограничение |
|---|---|---|
| `EI_id` | INTEGER | PK-часть, FK → `educational_institution.id` |
| `EGAS_id` | INTEGER | PK-часть, FK → `EGAS.id` |

### student

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `name` | VARCHAR(255) | NOT NULL | Имя |
| `surname` | VARCHAR(255) | NOT NULL | Фамилия |
| `patronymic` | VARCHAR(255) | — | Отчество |
| `grade` | INTEGER | NOT NULL | Класс / курс |
| `student_group` | VARCHAR(255) | NOT NULL | Группа (в схеме названа `student_group`, т.к. `group` — резервное слово SQL) |
| `max_id` | INTEGER | NOT NULL | ID во внешней системе (MAX) |
| `login` | VARCHAR(255) | NOT NULL | Логин |
| `password` | VARCHAR(255) | — | Пароль |
| `experience` | INTEGER | NOT NULL, DEFAULT 0 | Накопленный опыт |
| `EI_id` | INTEGER | NOT NULL, FK → `educational_institution.id` | Учреждение |

### partner

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `name` | VARCHAR(255) | NOT NULL | Название |
| `max_id` | INTEGER | NOT NULL | ID во внешней системе (MAX) |

### bonus

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `promocode` | VARCHAR(255) | NOT NULL | Промокод |
| `need_experience` | INTEGER | NOT NULL | Требуемый опыт |
| `partner_id` | INTEGER | NOT NULL, FK → `partner.id` | Партнёр |
| `end_date` | DATE | — | Дата окончания действия |

### student_bonus

Связующая таблица (M:N `student` ↔ `bonus`).

| Колонка | Тип | Ограничение |
|---|---|---|
| `student_id` | INTEGER | PK-часть, FK → `student.id` |
| `bonus_id` | INTEGER | PK-часть, FK → `bonus.id` |

### admins

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `max_id` | INTEGER | NOT NULL | ID во внешней системе (MAX) |

### applications

| Колонка | Тип | Ограничение | Описание |
|---|---|---|---|
| `id` | INTEGER | PK, `GENERATED BY DEFAULT AS IDENTITY` | Автогенерируемый ID |
| `type` | VARCHAR(255) | NOT NULL | Тип заявки |
| `partner_name` | VARCHAR(255) | NOT NULL | Название партнёра |
| `description` | VARCHAR(255) | NOT NULL | Описание |
| `contact_details` | VARCHAR(255) | NOT NULL | Контакты |

> Примечание: `id` во всех таблицах — `GENERATED BY DEFAULT AS IDENTITY` (автоинкремент).
> Поля `max_id` — это ID во внешней системе MAX, их задаёт интеграция, не БД.

## Схема связей

```
subject 1──M city 1──M educational_institution 1──M student
              \                                          \
               `─M─┐                                 ┌────┘
      educational_institution M─N EGAS         student M─N bonus
                                            bonus M──1 partner
```
