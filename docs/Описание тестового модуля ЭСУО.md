# mock_egas

Мок-данные для ЭСУО «Сетевой город» (netschoolapi).

Пакет предоставляет фиксированные тестовые сценарии электронного дневника, полностью совместимые с библиотекой [`netschoolapi`](https://github.com/nm17/netschoolapi). Используется для разработки и тестирования бота без реального доступа к серверам ЭСУО.

---

## Что внутри

| Модуль | Описание |
|--------|----------|
| `models.py` | Классы `Assignment`, `Lesson`, `Day`, `Diary` — повторяют схемы netschoolapi. Методы `to_dict()` (уровень библиотеки) и `to_raw()` (сырой JSON сервера). |
| `scenarios.py` | 13 готовых сценариев недели (обычная, каникулы, праздники, оценки/н/а, просрочки, пустые кабинеты, несколько заданий на урок, плотная неделя, окна в расписании, крайние времена, субботние занятия и др.). |
| `__main__.py` | CLI: запуск проверок, вывод raw-JSON или текстового представления. |

Все даты **зафиксированы**: неделя **понедельник 2026-09-14 — воскресенье 2026-09-20**. Никакой зависимости от текущей даты.

## CLI

```bash
python -m mock_egas                    # сводка + валидация всех сценариев
python -m mock_egas --raw <имя>        # сырой JSON ответа сервера ЭСУО

```

Примеры:

```bash
python -m mock_egas --raw regular_week | head -40
python -m mock_egas --text graded_week
```

## Использование в коде

```python
from mock_egas.scenarios import SCENARIOS, scenario
from mock_egas.models import Diary

# Получить все сценарии
for name, factory in SCENARIOS.items():
    diary: Diary = factory()
    print(name, diary.start, diary.end)

# Получить конкретный сценарий
diary = scenario("regular_week")  # KeyError если нет

# Сериализация для netschoolapi
raw_json = diary.to_raw()      # как отдаёт сервер ЭСУО
lib_dict = diary.to_dict()     # как парсит netschoolapi

# Валидация своих данных
from mock_egas.__main__ import validate_diary
problems = validate_diary(my_diary)
if problems:
    print("Ошибки:", problems)
```

## Список сценариев

| Имя | Описание |
|-----|----------|
| `regular_week` | Обычная учебная неделя: 5 дней, оценки, комментарии, выходные пустые. |
| `week_without_lessons` | Каникулы/буквенные дни: 7 пустых дней. |
| `holiday_in_middle` | Праздник в среду, остальные дни учебные. |
| `graded_week` | У каждого задания стоит оценка 2–5. |
| `ungraded_week` | Все задания без оценок (`mark=None`, `is_duty=False`). |
| `duty_marks` | Задания с «н/а» (`is_duty=True`). |
| `overdue_assignments` | Дедлайны раньше начала недели (просроченные). |
| `lessons_without_room` | Уроки с пустым кабинетом (`room=""`). |
| `multi_assignment_lesson` | Один урок — несколько заданий разного типа. |
| `busy_week` | 7 дней × 7 уроков, у каждого задание (стресс-тест). |
| `no_assignments_week` | Только расписание, ни одного задания. |
| `sparse_schedule` | Пропуски номеров уроков (2, 3, 6 в один день). |
| `single_school_day` | Всего один учебный день за неделю. |
| `extreme_times` | Уроки с 8:00 и до 20:00 (вторая смена/факультативы). |
| `weekend_lessons` | Учебная суббота с уроками. |

---

## Инварианты (проверяются автоматически)

- Неделя ровно 7 дней: 2026-09-14 — 2026-09-20.
- В расписании 7 дней без пропусков и дублей.
- Дата урока совпадает с датой дня.
- Время начала < времени окончания.
- Номера уроков в пределах дня уникальны.
- `id` заданий уникальны во всём дневнике.
- У заданий с `is_duty=True` оценка всегда `None`.
- Оценки только из множества `{None, 2, 3, 4, 5}`.

## Структура «сырого» JSON (`to_raw()`)

Пример фрагмента (один день):

```json
{
  "weekStart": "2026-09-14",
  "weekEnd": "2026-09-20",
  "weekDays": [
    {
      "date": "2026-09-14",
      "lessons": [
        {
          "subjectName": "Алгебра",
          "number": 1,
          "startTime": "08:00",
          "endTime": "08:45",
          "room": "301",
          "assignments": [
            {
              "id": 101,
              "assignmentName": "Параграф 12, упражнения 1–5",
              "typeId": 4,
              "dueDate": "2026-09-15T00:00:00",
              "mark": {"mark": 5, "dutyMark": false},
              "markComment": {"name": "Отлично"}
            }
          ]
        }
      ]
    }
  ]
}
```

Поле `typeId` соответствует справочнику `ASSIGNMENT_TYPES` в `models.py`.
