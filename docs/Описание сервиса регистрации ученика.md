# Сервис регистрации ученика

Модуль `services/registration.py` — слой логики, который принимает данные
ученика от бота и сохраняет его в базе данных: шифрует пароль, пишет запись
через CRUD из `db/crud`, а после регистрации запрашивает данные об оценках
ученика в ЭСУО.

---

## Зоны ответственности

| Компонент | Что делает |
|-----------|-------------|
| `StudentRegistrationData` | Контракт данных, передаваемых ботом (dataclass). |
| `prepare_student_data()` | Подготавливает данные для записи в БД, шифрует пароль. |
| `encrypt_password()` / `decrypt_password()` | Обратимое шифрование пароля. |
| `register_student()` | Оркестратор: проверка дублей → запись → запрос оценок. |
| `fetch_student_grades()` | Запрос оценок ученика в ЭСУО (**TODO**: пока мок). |

---

## Поток регистрации

```
бот -> StudentRegistrationData -> register_student()
                                   ├─ 1. is_student(max_id)  — проверка дублей
                                   ├─ 2. prepare_student_data() — шифрование пароля
                                   ├─ 3. student_crud.create(session, **data) — запись в БД
                                   └─ 4. fetch_student_grades(student) — запрос оценок
```

Сессия БД открывается через `session_scope()` (см. `services/__init__.py`),
CRUD-методы берутся из `db/crud/student.py`.

---

## Использование

### Из хендлера бота

```python
from services.registration import StudentRegistrationData, register_student

# Бот собрал данные от пользователя:
data = StudentRegistrationData(
    name="Иван",
    surname="Петров",
    patronymic="Сергеевич",
    grade=9,
    student_group="А",
    max_id=12345,
    login="ivanlogin",
    EI_id=1,
    password="secret",
)

# Синхронный-по-восприятию вызов из async-хендлера:
student = await register_student(data)
```

`register_student` вернёт сохранённый объект `Student`. Если ученик с таким
`max_id` уже существует — поднимется `ValueError`.

### Только подготовка данных (без БД)

```python
from services.registration import StudentRegistrationData, prepare_student_data

prepared = prepare_student_data(data)
# prepared["password"] — уже зашифрован, готов к записи
```

## Шифрование пароля

Пароль шифруется **обратимо** (не хешируется), чтобы позже можно было
расшифровать его и авторизоваться в ЭСУО от имени ученика.

- Алгоритм: XOR-поток по байтам пароля с ключом + `base64.urlsafe`.
- Ключ: обязательная переменная окружения `EGAS_ENCRYPTION_KEY`
  (задаётся в `.env`, см. `.env.template`). Если не задана — сервис
  падает с `RuntimeError`. Ключ хранить в коде нельзя.
- Хранится в поле `password` таблицы `student` как строка.

```python
from services.registration import encrypt_password, decrypt_password

secret = encrypt_password("secret")          # -> "qHfJlZ...%3D"
decrypt_password(secret)                      # -> "secret"
```

## Связанные модули

- `db/crud/student.py` — CRUD: `create`, `get_by_max_id`, `get_by_login`, ...
- `services/auth.py` — `is_student(max_id)` — проверка существования ученика.
- `mock_egas/` — мок-сценарии дневника для разработки без реальной ЭСУО.
